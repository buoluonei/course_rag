# 课程资料 RAG 问答系统：简历参考

基于 Python、FastAPI 和 MySQL 的资料问答应用，支持 TXT、PDF、DOCX 文档解析、资料检索、多轮问答及文档管理。

- 使用文档结构和重叠窗口处理资料，将文本切分后存入数据库，保留文件及片段元数据。
- 实现 BM25 关键词检索与 BGE 语义检索，采用 RRF 融合候选，再使用 CrossEncoder 对候选重排序并生成模型上下文。
- 使用会话 ID 关联历史问答，提供文档上传、同名覆盖、删除、历史记录及网页交互接口。
- 以 Docker Compose 配置应用和 MySQL；使用参数化查询、文件格式与大小校验，并通过单元测试覆盖文档解析与检索模型加载等行为。

说明：接口返回的是检索候选来源，不保证每一条均被模型实际引用；现有测试并不证明检索质量或性能提升。请根据自己能够解释的实现和实际验证结果调整表述。

## 可以准备的面试问题

- 为什么将关键词检索和语义检索的排名融合？RRF 输入和输出分别是什么？
- CrossEncoder 重排序与向量召回的作用有什么区别？
- 文档发生变化时，索引缓存与实际内容如何保持一致？目前方案有什么性能限制？
- 文档解析、切分、向量检索、模型调用和保存问答分别在哪里完成？
- 当前系统为什么不能直接开放给多个公网用户？
